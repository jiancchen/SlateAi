# MLB Model Notes

Human-readable model notes for MLB cartridges live here when they are not owned directly by a cartridge folder.

Cartridge-owned notes should stay under `models/mlb/cartridges/{modelId}/`.

## MLB-M3

- `mlb-m3-constitution.md` is the required philosophy and drift-check document for MLB-M3 architecture, feature, harness, training, backtest, and promotion work.
- `mlb-m3-early-game-shape-v0-pipeline.md` maps the first real contract-first M3 pipeline: canonical event truth to starter/F5 structural targets to F5 O/U contract evaluation.
