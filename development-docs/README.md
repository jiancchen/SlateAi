# Development Docs

This folder is being migrated from a flat notes directory into sport-specific runbooks, research, and postmortems.

During migration, old top-level files may remain here until the scripts that write them are updated in the same change.

## Target Layout

- `mlb/`: MLB runbooks, research, model notes, and postmortems.
- `tennis/`: Tennis runbooks, research, model notes, and postmortems.
- `shared/`: Cross-sport architecture, data contracts, and UI notes.
- `archive/`: Historical notes that are no longer active runbooks.

Do not move generated or script-written docs unless the writer path is updated and tested at the same time.
