# May 25 Tennis Clay Arbitrage Scan

## How To Read This

This is not a winner-only sheet.

The screen is:
- market imbalance first
- recent clay resistance second
- service-hold / breakpoint path third

Direct player-vs-player H2H is sparse in a lot of first-round Roland Garros matches, so the useful proxy is:
- recent clay level
- whether the dog has held serve or pushed stronger opponents deep
- whether the favorite actually breaks cleanly on clay
- whether the first set can realistically reach `4-4`, `5-5`, or a tiebreak

- `Iga Swiatek vs Emerson Jones`
  Board: `98/2`. Same idea. Swiatek is the rightful favorite, but the contract is so expensive that a clean early underdog hold path creates tradable compression. Jones only matters if she can keep the first set serve-for-serve.

- `Veronika Erjavec vs Elena Rybakina`
