# TEN-F0 Tennis Feature Baseline

TEN-F0 is the tennis feature layer consumed by TEN-T0.

It owns the expectation that each snapshotted run has scoreboard context, TennisLive profile ranks, TennisLive recent matches, TennisLive stat rows, TennisLive form charts, sportsbook lines, Kalshi markets, and optional weather inputs available or explicitly marked missing by health checks.

TEN-F0 is not a standalone betting model. It exists so future feature changes can be tracked without blending them into winner logic or evaluator changes.
